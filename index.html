Sistema PMESP Operacional

Este projeto é uma interface demonstrativa desenvolvida para estudo, treinamento e simulação de um painel operacional.

Não possui integração com sistemas oficiais, bancos de dados governamentais ou informações reais de policiais, ocorrências ou cidadãos.
